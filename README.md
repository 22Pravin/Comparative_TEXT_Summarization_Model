# Text Summarization Using NLP Models

## Overview
This project explores and evaluates the effectiveness of various Natural Language Processing (NLP) models for text summarization. It leverages models like **BERT**, **XLNet**, and **GPT-2** to summarize long-form text extracted from PDFs and assesses their performance using evaluation metrics such as ROUGE. This project demonstrates how modern NLP techniques can handle information overload by condensing large textual data into concise summaries.

## Features
- Extract text from PDF files using **pdfplumber**.
- Summarize extracted text using pre-trained NLP models: **BERT**, **XLNet**, and **GPT-2**.
- Evaluate model performance using the **ROUGE** metric (ROUGE-1, ROUGE-2, ROUGE-L, and ROUGE-Lsum).
- Visualize model performance using **bar graphs** and **line charts**.
- Identify the most effective summarization model for different content types.

## Research Context
The project is based on the research paper titled "Performance Evaluation of Text Summarizing Models Applied to the Content Extracted from the PDFs" by Anusmita Guchhait, Chirayu Shah, Pravinkumar Gohil, Satwik Chauhan, and Mohit Angurala.

### Key Insights from the Research Paper:
- GPT-2 consistently outperforms BERT and XLNet in terms of summarization quality.
- ROUGE metrics are used to compare the summaries generated by the models against reference summaries.
- Summarization techniques include **extractive** (selecting important sentences) and **abstractive** (creating new sentences) approaches.

## Methodology
1. **Text Extraction**:
   - Input: PDF documents (biological and historical content types).
   - Text extracted using the **pdfplumber** library.

2. **Preprocessing**:
   - Tokenization and formatting of extracted text.

3. **Summarization**:
   - Models used: **BERT**, **XLNet**, and **GPT-2**.
   - Each model generates summaries for the input text.

4. **Evaluation**:
   - Reference summaries are compared with generated summaries using **ROUGE** metrics.
   - ROUGE metrics calculate precision, recall, and F1-scores.

5. **Visualization**:
   - Graphical representation of model performance.
   - Group bar graphs and line charts highlight key insights.

## Evaluation Metrics
- **ROUGE-1**: Overlap of unigrams (single words) between the generated and reference summaries.
- **ROUGE-2**: Overlap of bigrams (two-word pairs) between the summaries.
- **ROUGE-L**: Longest common subsequence between generated and reference summaries.
- **ROUGE-Lsum**: Incorporates the length of summaries into the evaluation.

## Results
- **GPT-2** emerges as the best-performing model for most cases, achieving higher ROUGE scores compared to BERT and XLNet.
- Performance varies depending on content type, highlighting the importance of selecting domain-specific models.
